ACL 2026 / Conference paper

Current Agents Fail to Leverage World Model as Tool for Foresight

An empirical study of whether vision-language agents can use external world models to anticipate action outcomes.

Cheng Qian, Emre Can Acikgoz, Bingxuan Li, Xiusi Chen, Yuji Zhang, Bingxiang He, Qinyu Luo, Gokhan Tur, Dilek Hakkani-Tür, Yunzhu Li, Heng Ji

01 / The question

Does access to a simulator help an agent make better decisions about the future?

02 / The approach

World Model as Tool

The study evaluates world-model use across agentic and visual question-answering tasks, then analyzes when agents simulate and how they interpret the results. Its findings motivate better policies for invoking simulation and integrating predicted outcomes into decisions.
