ICLR 2025 / Conference paper

Proactive Agent: Shifting LLM Agents from Reactive Responses to Active Assistance

Learning when an agent should offer help, using observations of user activity and feedback on proposed tasks.

Yaxi Lu, Shenzhi Yang, Cheng Qian, Guirong Chen, Qinyu Luo, Yesai Wu, Huadong Wang, Xin Cong, Zhong Zhang, Yankai Lin, Weiwen Liu, Yasheng Wang, Zhiyuan Liu, Fangming Liu, Maosong Sun

01 / The question

Can an agent recognize a useful next step before the user explicitly asks for help?

02 / The approach

Proactive Agent

The work combines activity-based task prediction, human acceptance labels, a learned evaluator, and the ProactiveBench data pipeline. Fine-tuning studies examine how these signals help agents decide when and how to offer assistance.
