EMNLP 2024 / Conference paper

RepoAgent: An LLM-Powered Open-Source Framework for Repository-level Code Documentation Generation

An open-source agent that generates and maintains documentation with a view of the whole code repository.

Qinyu Luo*, Yining Ye*, Shihao Liang, Zhong Zhang, Yujia Qin, Yaxi Lu, Yesai Wu, Xin Cong, Yankai Lin, Yingli Zhang, Xiaoyin Che, Zhiyuan Liu, Maosong Sun

* Equal contribution.

01 / The question

How can documentation stay useful as a repository grows and its code changes?

02 / The approach

RepoAgent

RepoAgent uses language models to generate repository-level documentation and update it alongside code changes. The framework connects documentation generation with repository understanding, supporting an ongoing development workflow.
